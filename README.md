# Simple Command Line Note Manager

This Python script demonstrates a simple command-line note manager. It showcases fundamental programming concepts like data structures (lists), control flow (loops, conditionals), and basic input/output, which are often among the first topics taught in a Computer Science curriculum. It serves as a basic example of how foundational programming skills are built, contrasting with initial grand expectations of building complex applications.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Open a terminal or command prompt.
3. Navigate to the directory where you saved the file.
4. Run the script using `python main.py`.
